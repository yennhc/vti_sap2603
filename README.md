# VTI SAP 2603 - Course Materials

This repository contains the learning materials and exercises for the VTI SAP 2603 training program. The course covers foundational IT infrastructure topics, focusing on Linux administration, networking, and routing.

## Course Content

*   **[Day 1: Linux OS](./Day1.Linux_OS/)**: Introduction to the Linux Operating System, distributions, and basic concepts.
*   **[Day 2: CLI](./Day2.CLI/)**: Command Line Interface basics, navigation, file manipulation, and essential commands.
*   **[Day 3: Software Management](./Day3.Software/)**: Package management, installing, updating, and removing software in Linux.
*   **[Day 4: File Permissions](./Day4.Permission/)**: Understanding user roles, groups, and managing file/directory permissions (chmod, chown).
*   **[Day 5: SSH](./Day5.SSH/)**: Secure Shell configuration, remote access, key-based authentication, and secure file transfer.
*   **[Day 6: Cronjob](./Day6.Cronjob/)**: Task scheduling and automation using Cron.
*   **[Day 7: Networking Basics](./Day7.Network/)**: Fundamental networking concepts, OSI model, IP addressing, and subnetting.
*   **[Day 8: Switching](./Day8.Switch/)**: Layer 2 switching concepts, VLANs, trunking, and basic switch configuration.
*   **[Day 9: Routing](./Day9.Routing/)**: Layer 3 routing concepts, static routing, dynamic routing protocols.

## How to use this repository

Navigate to the respective day's folder to access the materials, notes, and lab exercises for that topic.
