CISCO PACKET TRACER

LAB: VTP + Router + DHCP

Đồng bộ VLAN qua VTP, định tuyến Inter‑VLAN bằng Router‑on‑a‑Stick, và cấp phát IP tự động bằng DHCP cho từng VLAN.

VTP Domain · LAB VLAN 10 · SALES VLAN 20 · IT Router 2911 · DHCP
🎯

Mục tiêu bài lab

01
VTP đồng bộ VLAN
SW1 (Server) tạo VLAN, SW2 (Client) tự động nhận về qua đường trunk.
02
Router cấp DHCP
Router làm DHCP server, cấp dải IP riêng cho từng VLAN.
03
Laptop nhận IP tự động
Máy ở mỗi VLAN nhận đúng dải IP và ping được nhau qua Inter‑VLAN.
🧱

Sơ đồ mạng (Topology)

VLAN 10 (SALES)
VLAN 20 (IT)
Trunk 802.1Q

Các bước cấu hình

Mỗi bước gồm sơ đồ minh hoạ và đoạn lệnh cấu hình tương ứng.

1

Tạo VLAN trên VTP Server (SW1)

SW1 ở chế độ server tạo VLAN, SW2 ở chế độ client sẽ tự động đồng bộ.

SW1 — VTP Server
conf t
vtp domain LAB
vtp mode server
vlan 10
name SALES
vlan 20
name IT
SW2 — VTP Client
conf t
vtp domain LAB
vtp mode client
💡

SW2 phải cùng VTP domain (LAB) thì mới nhận được VLAN từ Server. Không cần tạo VLAN thủ công trên SW2.
2

Cấu hình Trunk

Bật trunk giữa SW1↔SW2 (fa0/1) và SW1↔Router (fa0/24) để truyền nhiều VLAN.

SW1 → SW2
interface fa0/1
switchport mode trunk
SW1 → Router
interface fa0/24
switchport mode trunk
💡

Cổng nối Router phải là trunk để mang được cả VLAN10 và VLAN20 — đây là điều kiện cho Router‑on‑a‑Stick.
3

Gán port cho Laptop

Cổng fa0/2 của mỗi switch đặt ở chế độ access và gán đúng VLAN.

SW1 · Laptop1 (VLAN10)
interface fa0/2
switchport mode access
switchport access vlan 10
SW2 · Laptop2 (VLAN20)
interface fa0/2
switchport mode access
switchport access vlan 20
4

Cấu hình Router 🚀 (DHCP + Inter‑VLAN)

Router Cisco 2911 — tạo sub‑interface cho mỗi VLAN, sau đó cấp DHCP.

R1 — Sub‑interface
conf t
interface g0/0
no shutdown
interface g0/0.10
encapsulation dot1Q 10
ip address 192.168.10.1 255.255.255.0
interface g0/0.20
encapsulation dot1Q 20
ip address 192.168.20.1 255.255.255.0
R1 — DHCP
ip dhcp excluded-address 192.168.10.1 192.168.10.10
ip dhcp excluded-address 192.168.20.1 192.168.20.10
ip dhcp pool VLAN10
network 192.168.10.0 255.255.255.0
default-router 192.168.10.1
dns-server 8.8.8.8
ip dhcp pool VLAN20
network 192.168.20.0 255.255.255.0
default-router 192.168.20.1
dns-server 8.8.8.8
5

Laptop nhận IP 💻

Trên mỗi laptop trong Packet Tracer: Desktop → IP Configuration → DHCP.

PACKET TRACER · LAPTOP
1Mở tab Desktop
2Chọn IP Configuration
3Tích chọn DHCP → nhận IP tự động
👉Kết quả mong đợi
VLAN10 → IP 192.168.10.x
VLAN20 → IP 192.168.20.x
6

Verify 🔍 — Kiểm tra cấu hình

Dùng các lệnh show để xác nhận hệ thống hoạt động.

Trên Router
show ip dhcp binding
Trên Switch
show vlan brief
show interfaces trunk
CHECKLIST
✓Laptop xuất hiện trong bảng dhcp binding
✓VLAN 10 & 20 hiện đủ trên cả hai switch
✓Cổng fa0/1 & fa0/24 ở trạng thái trunking
🌐

Test — Ping giữa 2 Laptop

C:\\> ping 192.168.20.x
Reply from 192.168.20.x: bytes=32 time<1ms
✅

Nếu ping OK → định tuyến Inter‑VLAN qua Router‑on‑a‑Stick đã hoạt động.
